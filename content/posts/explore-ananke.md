## What is Ananke?

Ananke is a popular theme for [Hugo](https://gohugo.io), designed to be fast, flexible, and easy to use. It supports a beautiful hero image, post listing grid, and is responsive by default.

- [Ananke Theme Demo](https://ananke-theme.netlify.app/)
- [Theme Configuration Options](https://github.com/theNewDynamic/gohugo-theme-ananke#configuration)

### How to Customize

Edit the `[params]` in your `config.toml` file to change the hero image, subtitle, colors, and more!

```toml
[params]
  hero_image = "/my-ananke-project/images/hero.jpg"
  hero_subtitle = "Learning Hugo the Fun Way!"
```
