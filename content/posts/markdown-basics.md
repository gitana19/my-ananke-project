## What is Markdown?

Markdown is a simple, readable markup language that’s perfect for creating content for Hugo.

### Basic Syntax

- **Headers:**  
  `# Big Title`  
  `## Section`  
- **Bold/Italics:**  
  `**bold**`, `*italic*`
- **Lists:**  
  `- Bullet item`  
- **Links:**  
  `[Hugo Docs](https://gohugo.io/documentation/)`
- **Images:**  
  `![Example](/my-ananke-project/images/example.jpg)`

### Try it Yourself!

```markdown
## My Section Title

Here's some descriptive text about Hugo and Ananke!

- Fast setup
- Simple Markdown writing

[Learn more](https://commonmark.org/help/)
```
