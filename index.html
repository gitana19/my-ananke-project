Getting to Know the Ananke Theme

What is Ananke?

Ananke is a popular theme for Hugo, designed to be fast, flexible, and easy to use. It supports a beautiful hero image, post listing grid, and is responsive by default.

  • Ananke Theme Demo
  • Theme Configuration Options

How to Customize

Edit the [params] in your config.toml file to change the hero image, subtitle, colors, and more!

[params]
  hero_image = "/my-ananke-project/images/hero.jpg"
  hero_subtitle = "Learning Hugo the Fun Way!"

Want to tweak the homepage and card layouts?
Explore the theme’s example site in the repo:
https://github.com/theNewDynamic/gohugo-theme-ananke/tree/master/exampleSite
